Data yang Kami Kumpulkan

ManualNest tidak memerlukan akun dan tidak mengumpulkan data pribadi di server kami. Aplikasi ini menyimpan semua data Anda secara lokal di perangkat Anda. Ini dapat mencakup nama item, merek, model dan nomor seri, ruangan, tanggal pembelian, harga, nama toko, tanggal kedaluwarsa garansi, catatan suku cadang, ukuran filter dan baterai, interval perawatan, catatan pemecahan masalah, dan catatan umum apa pun yang Anda masukkan.

Foto, Tanda Terima, dan PDF

Jika Anda memilih untuk melampirkan foto, gambar tanda terima, atau PDF manual, ManualNest menyimpannya di dalam folder pribadi aplikasi di perangkat Anda. Kamera dan pemilih foto hanya digunakan untuk file yang Anda pilih. File-file ini tetap ada di perangkat Anda kecuali Anda mengekspor atau membagikannya sendiri.

Panggilan Jaringan

ManualNest tidak melakukan panggilan jaringan selama penggunaan normal. Satu-satunya pengecualian adalah ketika Anda mengetuk URL manual yang Anda simpan sendiri pada suatu item — membuka tautan itu langsung ke browser default perangkat Anda.
