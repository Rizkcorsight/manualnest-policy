# ManualNest privacy policy

The privacy policy for [ManualNest](https://github.com/Rizkcorsight) — an offline-first household vault for owner manuals, warranties, receipts, model and serial numbers, parts, and maintenance schedules.

- [`privacy-policy.md`](./privacy-policy.md) — plain-text policy
- [`index.html`](./index.html) — styled version served via GitHub Pages

Once Pages is enabled, this site is reachable at:
**https://rizkcorsight.github.io/manualnest-policy/**
